# Covert Dialect Bias and Linguistic Profiling at Scale

Code and supplementary material for

> Chowdhury Mohammad Abdullah and Rita Orji. 2026. *From a River in Gilead to the Inference Distributions of Large Language Models: Covert Dialect Bias and Linguistic Profiling at Scale.* In Proceedings of the Ninth AAAI/ACM Conference on AI, Ethics, and Society (AIES 2026), Malmö, Sweden.

## Contents

| Path | Content |
|---|---|
| `SUPPLEMENTARY.md` | Translation protocols and validation, models, prompt templates, lexicons, statistical results, null-attribute baseline, perplexity |
| `CLARIFICATIONS.md` | Notes on reading three passages of the paper |
| `notebooks/` | Scoring for the three scenarios (01 to 03), statistical tests (04) and null-attribute baseline (05) |
| `lexicons/` | Adjective lexicons for the three housing scenarios |
| `dataset/` | Placeholder showing the corpus format |

The sentence corpus is not included.
